# MikDeli
# 🌐 MikDeli Website

Site web responsive realizat folosind **HTML, CSS și JavaScript**.

Proiectul a fost creat pentru a prezenta într-un mod modern și atractiv produsele și informațiile despre MikDeli.

## 📌 Despre proiect

Site-ul conține mai multe secțiuni, printre care:

- Pagina principală
- Despre noi
- Produse
- Galerie
- Recenzii
- Contact
- Meniu separat
- Design responsive pentru telefon, tabletă și PC

## 🛠️ Tehnologii utilizate

- HTML5
- CSS3
- JavaScript
- Responsive Design
- CSS Animations

## 📱 Responsive Design

Site-ul este optimizat pentru mai multe dispozitive:

- 💻 Desktop
- 📱 Smartphone
- 📲 Tabletă

Interfața se adaptează automat în funcție de dimensiunea ecranului.

## 📂 Structura proiectului

```text
MikDeli/
│

├── style.css

├── menu.css
```

## 🚀 Rularea proiectului

Poți deschide proiectul direct prin fișierul:

```text
index.html
```

Pentru o experiență mai bună este recomandată utilizarea extensiei **Live Server** în Visual Studio Code.

## 🌍 GitHub Pages

Site-ul poate fi publicat gratuit folosind **GitHub Pages**.

După publicare, acesta poate fi accesat de pe orice dispozitiv printr-un link de forma:

```text
https://username.github.io/MikDeli/
```

## ✨ Funcționalități

- Navigare modernă
- Meniu pentru dispozitive mobile
- Animații și tranziții
- Galerie foto
- Secțiune produse
- Secțiune recenzii
- Informații de contact
- Detectarea programului deschis/închis
- Adaptare pentru diferite dimensiuni ale ecranului

## 🎨 Design

Design-ul folosește o combinație de culori inspirată de stilul unei brutării și patiserii moderne, cu elemente în nuanțe de:

- maro închis
- crem
- verde

Interfața este concepută pentru a fi simplă, elegantă și ușor de utilizat.
